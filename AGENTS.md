This repository publishes the `bun create shallot` scaffold.

Checks: `bun run check` and `bun run test`.

Package states: https://github.com/dylanebert/shallot/blob/main/CONTRIBUTING.md#dependencies

In local development, record producer and consumer HEAD and dirt before linking, rerun the focused gate after leaving local, and unlink the producer registration once it is no longer needed. Temporary packs, caches and generated applications belong under `/tmp`.
